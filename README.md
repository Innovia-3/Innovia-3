### Databas:    
Vi använder PostgreSQL som vår relationsdatabas. Under utvecklingsfasen använder vi Docker för att alla i gruppen ska använda samma databaskonfiguration. Vi behöver alltså inte installera postgres på alla datorer utan det ingår med Docker förutsatt att alla har Docker Desktop på sin dator.
